# Direção aprovada — Compacto

Em 30/09/2026 o usuário aprovou a proposta navegável do Enlace, após selecionar **Compacto**. Este precedente prevalece sobre o shell genérico do template.

- Carteira em linhas claras, com identificação do projeto e arquitetura/execução lado a lado.
- Navegação discreta, área de trabalho dominante, tipografia de sistema e paleta aprovada em IDENTIDADE.md.
- Mapa: selecionar destaca conexões sem reorganizar os nós; a ação Detalhes abre o inspetor.
- Abas Elemento/Fluxo, descrição curta e fontes recolhidas. Apoio aparece mediante expansão.
- Assistente flutuante contextual; uma única camada modal, com Escape e foco restaurado.
- Arquitetura declarada e execução observada têm o mesmo peso. Ausência de conector não vira zero de atividade.

Referências: Linear (navegação/hierarquia), React Flow (interação do grafo), Langfuse (inspeção). Código independente, sem copiar componentes destes produtos.

O protótipo usava exemplos. O produto usa somente registros locais reais e estados vazios explícitos.
